# workspaces/cathlab-schedule-ocr/

Runtime workspace for the `cathlab-schedule-ocr` skill.

Holds at runtime (all gitignored):

- `inbox/` — incoming schedule images / Word files.
- `sources/` — raw OCR inputs by date.
- `history/` — past extraction runs as JSON.
- `outputs/` — emitted TSV files (when in TSV mode).
- `captures/` — screenshots from validation steps.

Never committed.
