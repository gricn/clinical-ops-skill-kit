# diagrams/

This directory holds portfolio-facing diagrams for the public skill kit.

Use these diagrams when a reader needs to understand the system shape before reading individual `SKILL.md` files. They are meant for README embedding, architecture review, and interview walkthroughs.

This directory does not cover runtime evidence, private production data, credentials, or screenshots from live business systems.

## Files

- `skill-map.svg` — English workflow map. It groups the 15 skills into five business workflow groups, then shows shared backend, safety gates, runtime isolation, and self-iteration.
- `skill-map.zh-CN.svg` — Chinese version of the workflow map.
- `ops-loop.svg` — English plain-language operations loop for readers who do not know the domain.
- `ops-loop.zh-CN.svg` — Chinese version of the operations loop.
- `engineering-layers.svg` — English engineering layer diagram showing capability/runtime/secrets/governance boundaries.
- `engineering-layers.zh-CN.svg` — Chinese version of the engineering layer diagram.
